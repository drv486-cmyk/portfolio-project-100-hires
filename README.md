# Portfolio Project – 100Hires Job Application

## Tools I Installed

- **Cursor IDE** – Downloaded and installed from https://cursor.com/
- **Claude Code for VS Code** – Installed via Cursor Extensions (by Anthropic, 22M downloads)
- **Codex** – Installed via Cursor Extensions (by OpenAI, 8.4M downloads)
- **Git** – Installed from https://git-scm.com/ to enable version control

## Steps I Completed

1. Installed Cursor IDE and created an account
2. Connected my GitHub account (drv486-cmyk) to Cursor
3. Searched for and installed the Claude Code extension in Cursor
4. Searched for and installed the Codex extension in Cursor
5. Created a public GitHub repository called `portfolio-project-100-hires`
6. Cloned the repository to my local machine using Git
7. Opened the repository folder in Cursor
8. Created and edited this README.md file
9. Committed and pushed changes to GitHub

## Issues I Ran Into and How I Solved Them

**Issue 1: Git not recognized**
When I tried to run `git clone` in the Cursor terminal, I got an error saying
"git is not recognized as a command". I searched for a solution, found that
Git needs to be installed separately, downloaded it from git-scm.com,
installed it, restarted Cursor, and the command worked successfully.

**Issue 2: `code .` command not working**
After navigating into the project folder, I tried running `code .` to open it
but got an error. I solved this by using File → Open Folder in Cursor instead,
which opened the project correctly.
